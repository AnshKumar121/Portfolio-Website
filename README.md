# Portfolio-Website

## Description
A responsive portfolio website created using HTML5 and CSS3.

## Features
- Home Page
- About Page
- Contact Page
- Responsive Design
- CSS Grid
- Flexbox
- Media Queries
- Hover Effects

## Deployment

### GitHub Pages
1. Push project to GitHub.
2. Open Settings > Pages.
3. Select Main Branch.
4. Save.

### Netlify
1. Upload project folder.
2. Deploy instantly.
